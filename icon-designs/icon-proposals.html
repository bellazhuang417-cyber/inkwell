HtmlNote — App Icon 设计提案

Personal Knowledge Archiver · Kami Design System · 3 个方案对比

方案 A

抽象几何 · Code & Note

以 HTML 标签的尖括号 `< >` 为视觉锚点，融合文档折角的笔记元素。墨蓝色主调搭配暖米色背景，几何形态干净利落，在 Dock 小尺寸下轮廓清晰可辨。

方案 B

字母标志 · Serif H

基于 "H" (HtmlNote) 的衬线字体 monogram。使用霞鹜文楷风格衬线体，H 的两竖笔画融入纸张纹理意象——左竖为实、右竖带微妙的渐变层次。经典而温暖。

方案 C

质感系 · Vellum & Ink

羊皮纸/书籍元素 + 墨水滴落意象。打开的笔记本轮廓中，一抹墨蓝色笔触从上方自然流淌，呼应 Vellum（犊皮纸）的产品命名方向。最富叙事性，辨识度最高。
